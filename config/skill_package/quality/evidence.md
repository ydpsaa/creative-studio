# Уровни обоснованности

| Уровень | Значит | Как использовать |
|---|---|---|
| **автор объяснил** (`author_explained`) | автор источника прямо дал это как совет (есть цитата) | можно опираться; его цифры/охваты — его утверждения |
| **наблюдается** (`observed`) | приём виден/слышен в примере, но автор его не объяснял | приём существует; эффективность не доказана |
| **гипотеза** (`hypothesis`) | объяснение аналитика «почему работает» | только как творческий выбор с пометкой риска |
| **предпочтение пользователя** (`user_preference`) | владелец явно так решил | обязательно в своей области действия |
| **подтверждено проектом** (`project_confirmed`) | есть зафиксированный результат | сильнейший уровень (пока таких нет) |

Тэг `needs-review` = утверждение не удалось проверить имеющимися данными.
