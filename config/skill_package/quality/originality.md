# Оригинальность

Переносится **механика** (как устроено), не **содержание** (что именно сказано/показано).

| Можно | Нельзя |
|---|---|
| «итог в первой фразе, потом путь» | пересказать пример автора (оффер Apple, ремонт кухни за 400 000) |
| «5 звуковых карточек без музыки» | взять те же 5 звуков и подписи |
| «дословные субтитры, нарастающие по слову» | копировать шрифт/расположение/цвет конкретного автора 1:1 |
| «3D-стол с карточками, движение камеры» | воспроизвести их сцену с машиной в лесу |

Проверка перед сдачей: для каждого образа и фразы ответьте «откуда это?». Если из `examples/` — замените.
