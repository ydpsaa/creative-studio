# Инструкция для агента (Codex, ChatGPT, любой LLM с доступом к файлам)

1. Прочитайте `SKILL.md` целиком — это рабочий процесс и обязательные правила.
2. По шагам `workflow/01…05` выполните задачу пользователя.
3. Приёмы берите только из `methods/` (выбор — через `methods/SELECTION.md`), бренды — из `brands/`, предпочтения — из `preferences.md`.
4. Результат оформляйте по `templates/` и проверяйте по `quality/rubric.md` перед сдачей.
5. Не ищите внешние инструменты: всё нужное лежит в этой папке.
