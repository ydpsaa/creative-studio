# Задание на запись голоса

- **Ролик:** … · **язык:** … · **длительность:** ≈ … с
- **Подача:** (из профиля бренда, например: спокойно и уверенно, как разговор с одним человеком)
- **Как записать:** одна реплика — одна строка; можно одним дублем или отдельными файлами; тихое помещение, телефон в 15–20 см.

| № | Реплика (дословно) | Пометки (пауза, ударение, темп) | Целевое время |
|---|---|---|---|
| 1 | | | |

После записи тайминги и субтитры пересчитываются по реальной дорожке. В `assets.csv` голос — отдельный ассет со статусом «записать голос». Синтетическую замену не делать, если профиль бренда её не разрешает (если профиль разрешает синтетический голос, вместо задания на запись сдаётся `templates/elevenlabs-prompt.md`).
