# Промпт озвучки ElevenLabs (если профиль бренда разрешает синтетический голос)

- **Модель:** Eleven v4 (`eleven_v4`). **Голос:** из профиля бренда. **Speed:** 0.95–1.0.
- Аудиотеги в квадратных скобках перед фразой: эмоция и подача (`[low, calm voice]`, `[curious]`, `[mischievously]`), неречевые (`[sighs]`, `[exhales]`, `[pauses]`). Описательный тег надёжнее двусмысленного.
- Паузы — многоточием и пунктуацией (SSML `<break>` не поддерживается). Ударение — ЗАГЛАВНЫМИ.
- Название бренда пишется так, как его надо произнести (например, необычное название — фонетически); на экране — точное написание.
- Сделать 3–4 генерации, выбрать лучшую; тайминги и субтитры пересчитать по реальной дорожке.

```text
[тег подачи] Реплика 1... [pauses]

[тег подачи] Реплика 2.
```
