# Шаг 3. Создание

Порядок и шаблоны:

| Документ | Шаблон | Что важно |
|---|---|---|
| Концепция | `templates/concept.md` | одна мысль ролика + почему именно такая форма; ссылки на методы |
| Hooks | `templates/hooks.md` | ≥3 **разных по механике** варианта (не перефразы), у каждого — метод; рекомендованный вариант |
| Сценарий | `templates/script.md` | блоки с оценкой времени; поворот/перезацеп в середине, если ролик ≥ 20 с |
| Озвучка | `templates/voiceover.md` | чистый текст + отдельные указания по произнесению (паузы, ударения, темп) |
| Раскадровка | `templates/storyboard.csv` (+ `.md`) | на каждую сцену: время (оценка), визуал/действие, голос, текст на экране, звук, переход, ассет/задача, `basis` |
| Ассеты | `templates/assets.csv` | есть / снять / найти / сгенерировать; статус использования |
| Промпты | `templates/generation-prompts.md` | конкретные промпты для недостающих кадров, без брендов и узнаваемых чужих элементов |
| Запись голоса | `templates/recording-task.md` | если голос владельца ещё не записан |
| Монтаж | `templates/edit-notes.md` | порядок, темп, переходы, титры, звуковые акценты, громкость |

Все длительности до записи — **плановые** (так и подписывать). Скорость речи для оценки: русский 2,3–2,7 слова/с, английский 2,4–2,8 слова/с (спокойная подача — нижняя граница). Сумма сцен должна совпадать с длительностью брифа ±10 %. Проверьте плотность: слова чистого текста озвучки ÷ длительность. Больше ~150 слов/мин (2,5 слова/с) при действиях и паузах в кадре — сократите текст или увеличьте длительность.
