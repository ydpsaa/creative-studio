# Шаг 4. Самопроверка

Пройдите `quality/rubric.md` по каждому пункту и исправьте провалы до сдачи. Минимум для сдачи — все пункты «обязательно».
Дополнительно:
- Прочитайте сценарий вслух мысленно: нет ли приветствия/долгого захода, понятен ли ролик без звука (титры).
- Проверьте каждую строку раскадровки: есть ли `basis`, конкретен ли источник визуала.
- Сравните с примерами из `examples/`: нигде ли не скопирован сюжет, фраза, графика.
