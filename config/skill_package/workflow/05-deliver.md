# Шаг 5. Сдача

Сдайте папку/набор файлов по `templates/` (или один документ с теми же разделами) и в конце:

1. **Основания** — таблица: метод (ID и название) · где применён (сцена/строка) · уровень обоснованности · почему.
2. **Допущения** — что решено без данных брифа/бренда.
3. **Риски и гипотезы** — какие решения опираются на гипотезы или «требует проверки».
4. **Открытые вопросы** — максимум 3, только существенные.
5. **Версия методики** — версия этого пакета из `provenance/manifest.json`.
