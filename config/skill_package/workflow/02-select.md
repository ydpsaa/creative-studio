# Шаг 2. Выбор приёмов

1. Откройте `methods/SELECTION.md` и найдите задачи ролика: начало, удержание, структура, финал/CTA, визуал, звук, производство без лица.
2. Для каждого кандидата прочитайте карточку целиком: **когда не применять**, **условия**, **ограничения**, **область бренда**.
3. Отбросьте приёмы, которые противоречат брифу, бренду или режиму (например, split-screen с говорящей головой — не для `voice_only`).
4. Выбирайте приёмы по задаче и ограничениям брифа — столько, сколько нужно ролику (короткому спокойному объяснению может хватить двух). Для каждого объясните, какую проблему он решает. Сцена может опираться на изученный метод, факт брифа или явно помеченное «собственное решение». Количество методов само по себе качество не определяет.
5. Запишите выбор в таблицу «Основания»: ID — зачем — уровень обоснованности — риск.
6. Если для задачи в папке нет изученного приёма — решение помечается «собственное решение (вне базы)». Известные пробелы — `quality/known-gaps.md`.

Приоритет при конфликте: требования брифа → предпочтения бренда → предпочтения студии → *автор объяснил* → *наблюдается* → *гипотеза*.
