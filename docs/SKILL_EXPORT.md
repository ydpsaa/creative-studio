# Переносимый творческий навык

## Что это
Папка `dolishx-creative-method/` — самостоятельный навык: методы, условия, примеры, шаблоны, профили брендов, предпочтения и критерии качества. Агент, получивший только её и бриф, создаёт концепцию, hooks, сценарий, озвучку, раскадровку, ассеты, промпты и монтажное задание по методике владельца. Студия, SQLite, localhost, исходные видео и история переписки не нужны.

## Как получить
- UI: «Настройки → Переносимый творческий навык → Экспортировать новую версию» → «скачать ZIP».
- CLI: `./studio export-skill` → `studio-data/exports/skills/dolishx-creative-method/v<N>/` (папка + ZIP).
- Проверка любой копии: `./studio check-skill <папка>` (обязательные файлы, отсутствие абсолютных путей/localhost/БД/внутренних терминов, все `kn_…` существуют, ссылки не битые, SHA-256 по манифесту).
- Проверка работы, сделанной по навыку: `./studio check-skill-output <папка навыка> <папка работы>` (ID методов существуют, у каждой сцены есть `basis`, длительность, совпадения 6-словных фраз с примерами).

## Состав пакета
| Часть | Откуда | Как обновляется |
|---|---|---|
| `SKILL.md`, `README.md`, `AGENTS.md`, `workflow/`, `templates/`, `quality/`, `selftest/` | `config/skill_package/` (написано вручную) | правкой этих файлов |
| `methods/` (+ `INDEX.md`, `SELECTION.md`) | активные нетестовые карточки | автоматически при экспорте |
| `examples/` | последние разборы источников, на которые ссылаются карточки | автоматически |
| `brands/`, `preferences.md` | профили брендов; предпочтения областей `studio` и `brand` | автоматически |
| `provenance/manifest.json` | версия, история версий каждого правила, источники, контрольные суммы | автоматически |
| `provenance/CHANGELOG.md` | разница с предыдущим экспортом (добавлено/удалено/обновлено) | автоматически |
| `provenance/LIMITATIONS.md` | границы методики | автоматически |

## Версии и происхождение
- Версия = `<номер экспорта>.<дата>`; каждый экспорт — новая папка `v<N>`, старые не перезаписываются.
- Для каждого метода в манифесте: уровень обоснованности, область бренда, происхождение (`analysis:<источник>:v<N>:<кто>`), полная история версий с причинами правок.
- Предпочтения: только `studio` и `brand`; правки `project`/`clip` не входят (в `preferences.md` указано их число).

## Как передать агенту
- **Claude Code:** положить папку в `.claude/skills/` проекта или дать доступ к папке; навык найдётся по `SKILL.md`.
- **Claude.ai / Projects:** загрузить ZIP или файлы; первым сообщением — «следуй SKILL.md».
- **Codex / ChatGPT с доступом к файлам:** открыть папку; агент читает `AGENTS.md` → `SKILL.md`.
