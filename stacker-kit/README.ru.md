# STACKER — набор для стиля

**English — [README.md](README.md)**

STACKER — стиль коротких роликов. Слова появляются ровно в такт голосу и складываются стопкой в горизонтальной полосе 4:3. На ключевые слова падают стикеры с белой высечкой, под заставку звучат сухие акценты. Потом идёт жёсткая склейка на автора, который говорит в кадр.

В наборе всё, чтобы сделать такой ролик сегодня:
- описание стиля (ниже);
- рендер;
- 162 готовых стикера XEROX;
- промпты и инструмент для своих стикеров.

> Формат «стопки слов» популярен в коротких видео. Этот набор — наша собственная реализация: код, стикеры и звуки заставки [Dolishx](#ссылки) сделал с нуля.

## 1. Из чего состоит стиль

**Кадр.** Ролик вертикальный, 9:16 (1080×1920). Картинка стоит в **горизонтальной полосе 4:3** по центру (1080×812, y 554…1366), сверху и снизу чёрное. И заставка, и говорящая часть идут в этой полосе.

**Цвет полосы — один на выпуск.** Например, синий `#0E1E5C`, бордовый `#870000` или почти чёрный `#020002`.

**Заставка (первые 6–12 с) собирается по страницам:**

| Страница | Что происходит |
|---|---|
| **Стопка** | 2–3 строки по 1–3 слова. Строчные буквы, жирный гротеск, плотный трекинг, белый цвет, скромный кегль (около 6% ширины кадра). У каждой строки свой сдвиг: слева, справа или по центру. Слово **включается ровно в момент, когда его произносят**. Анимации нет, весь эффект — в точности синхрона. |
| **Удар** | Одно слово ЗАГЛАВНЫМИ (НО, ВСЁ, КАК) самым жирным начертанием на всю ширину. Длинное слово режется на 2 строки. |
| **Стикер** | Падает через 0,3–0,5 с после последнего слова фразы, за один кадр, без анимации. Закрывает часть текста и занимает около 35–45% ширины полосы. |
| **Разрыв** | Последнее слово рвётся на части вокруг стикера (ГО / ТОВО, одна часть повёрнута на 90°). Внизу — счётчик серии (`01/30`). |

**Стикер — буквальная картинка ключевого слова**, а не украшение: «идея» → лампочка, «дедлайн» → песочные часы, «победа» → кубок. Стикеры чёрно-белые (ксерокс, растр или гравюра) с белой высечкой и мягкой тенью.

**Говорящая часть.** После склейки автор говорит в той же полосе 4:3. Субтитры — одна фраза в 2–4 слова, по центру на уровне груди или подбородка. Цвет — один акцентный (у нас янтарный `#FFB547`), без обводки и плашки.

**Звук.** Звуки есть только в заставке, в говорящей части — только голос:
- сухой щелчок на каждой новой строке;
- шлепок и низкий удар, когда падает стикер;
- короткий удар на слове-ударе;
- глубокий низкий бум, когда рвётся последнее слово;
- щелчок затвора на склейке.

Все звуки рендер генерирует кодом, лицензии не нужны. Можно подложить свои.

**Темп.** После фразы со стикером оставляйте паузу 0,3–0,6 с. После последнего слова заставки — около 1,5 с, чтобы разрыв успели увидеть.

## 2. Сделать ролик

Нужна Creative Studio, см. главный [README](../README.ru.md): macOS на Apple Silicon. Тайминги слов считает mlx-whisper, локально.

1. **Напишите заставку**: 3–5 страниц, которые цепляют одной мыслью. Потом — текст говорящей части.
2. **Запишите голос** или видео с собой, лучше горизонтально на телефон. Оставьте паузы, как в разделе «Темп».
3. **Сценарий.** Возьмите за основу [examples/im_done.json](examples/im_done.json):
   - в `pages` — слова заставки в порядке произнесения; на экране будет именно этот текст, а время берётся из голоса;
   - `voice` может быть тем же видео, что и `talk_video`;
   - стикеры выбирайте в [stickers/CATALOG.md](stickers/CATALOG.md);
   - без `voice` время считается по `script` — так можно посмотреть раскладку до записи.
4. **Проверьте кадры и соберите ролик:**
   ```bash
   ./studio stacker мой_ролик.json --preview 1,2.5,4
   ./studio stacker мой_ролик.json
   ```
   При первом запуске голос распознаётся, тайминги кэшируются рядом со сценарием. Если слово распознано неточно, рендер предупредит и оставит ваш текст.

Демо без голоса:
```bash
./studio stacker stacker-kit/examples/im_done.json
```

### Пусть AI сделает сам
Подключите студию к Claude Code ([docs/CONNECT.md](../docs/CONNECT.md)) и скажите обычными словами: *«Сделай стакер из моей записи ~/Movies/take3.mov про то, почему я перестал рассказывать идеи»*. Навык [.claude/skills/stacker-video](../.claude/skills/stacker-video/SKILL.md) научит Claude:
- написать страницы;
- подобрать стикеры точно под ключевые слова;
- собрать ролик, проверить кадры и поправить их.

## 3. Свои стикеры

1. В любой модели картинок сгенерируйте сетку 3×3 на группу. Промпты лежат в [tools/grid_prompts.json](tools/grid_prompts.json), предметы — в [tools/pack_list.json](tools/pack_list.json). Названия предметов замените на свои темы.
2. Один раз соберите вырезалку (macOS, Apple Vision):
   ```bash
   swiftc -O stacker-kit/tools/cutout.swift -o stacker-kit/tools/cutout
   ```
3. Нарежьте сетку на стикеры:
   ```bash
   .venv/bin/python stacker-kit/tools/make_stickers.py G19_coffee сетка.png "coffee cup" "laptop" …
   ```
   Нужно 9 названий по порядку.
